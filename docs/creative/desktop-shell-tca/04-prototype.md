## Core journey only（台账）

一条路径，6 个状态：

1. **Dock 打开** → 主窗落在「工作台账」
2. **扫一眼今天** → 热力 + 跨度图 + 捕获框就绪
3. **记下一条** → 回车捕获 → 跨度图出现新条
4. **点进任务** → 详情：状态 / 进展 / 编辑
5. **点空历史日** → 热力绿点仍在；跨度为空或稀疏；可回「今天」
6. **侧栏点 Agent / 晨报** → 同壳进入（旧内脏可接受）；⌘1 回台账

Agent 确认流、晨报阅读：**不在本周线框主路径**（壳预留入口即可）。

## Design brief

| 项 | 决定 |
|----|------|
| **主体题材** | 本地每日工作台——账本 + 时间跨度，不是聊天、不是新闻站 |
| **受众** | 一人（Yupeng）；键盘 + 指针；每天多次短会话 |
| **页面唯一工作（台账主屏）** | 让你在一个画面里完成：看今天 → 记一条 → 点进改状态 |
| **签名元素** | **跨度图作为主视觉平面**（占满详情区中下部）；热力是次级日历条，不是英雄 |
| **壳气质** | Loop / Luminare 向：半透明材料、柔和分隔、侧栏沉静；**不是**默认 SwiftUI 扁平灰皮 |

### 色（6）

避开紫渐变白底、奶油衬线陶土、黑底荧光、报纸密排。

| Token | 角色 | 建议方向（实现时可微调） |
|-------|------|--------------------------|
| `--bg-app` | 窗口底 | 冷石墨蓝灰 `#1C2128`（深）/ 浅雾蓝灰 `#EEF1F4`（浅） |
| `--bg-sidebar` | 侧栏 | 比 app 略深/略浊一层 |
| `--bg-panel` | 热力+捕获条、卡片 | 半透明材料（系统 `.regularMaterial` / Luminare 等价） |
| `--ink` | 主文字 | 近白 / 近墨，高对比 |
| `--accent` | 选中 lens、进行中、热力高档 | **海苔绿** `#3D8B6E`（非系统蓝默认堆） |
| `--warn` | 陈旧/危险删除 | 暖赭 `#C47A4A` |

### 字体角色

| 角色 | 用法 |
|------|------|
| **UI** | SF Pro（系统）— 侧栏、按钮、捕获 |
| **Data** | SF Mono / 等宽数字 — 日期、热力轴、跨度日列 |
| **Display** | 不用第二装饰字体；标题用 SF Pro Semibold，避免「又一套衬线品牌皮」 |

### 动效（有意、少）

1. 侧栏选中：短 fade / 内容交叉淡入（~180ms）  
2. 捕获成功：新跨度条插入，轻 spring  
3. 历史→今天：热力选中框移动，不整表闪白  

### 明确不做的视觉

- 紫/靛渐变 CTA  
- 英雄区大插画或统计条  
- 晨报报纸多栏排版搬进台账  
- Agent 聊天气泡皮套在台账上
